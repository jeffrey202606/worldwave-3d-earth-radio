# WORLDWAVE — 3D 地球电台地图（Prototype 06 当前版本）

一个全屏高清 3D 地球：8K 全球底图 + 近景在线卫星影像瓦片，5,000+ 个真实经纬度电台坐标点，点击绿色圆点即收听公开电台直播；大洲 / 国家名称贴合球面并按缩放分级显示。

> 本目录当前交付的是**纯地球页面**。`docs/`、`backend/`、`admin/`、`profile.html`、`index.ui.html`、`index.immersive.html` 及 `js/globe.js` 等是 Prototype 03–05 的历史原型文件，保留在磁盘上供回溯，**不再由本地服务器对外提供**（见 `tools/serve.py` 白名单）。历史设计说明见 `docs/`，以本 README 为当前实现的准绳。

## 快速开始

```bash
# 推荐：加固版静态服务器（白名单、gzip、缓存头、安全响应头、无目录列表）
python tools/serve.py --port 8003

# 或最简方式（不推荐用于对外演示：会暴露目录列表与历史文件）
python -m http.server 8003
```

打开 <http://127.0.0.1:8003/>。也可以直接双击 `WORLDWAVE-3D-Earth.html`——它是完全自包含的单文件版（含 Three.js、控制器、贴图、电台快照），`file://` 下即可渲染。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 / 方向键 | 旋转地球（首次交互后停止自动旋转） |
| 滚轮 / `+` `-` | 缩放到城市级（`0` 复位） |
| 点击绿色圆点 | 播放该位置电台；同址多台可用 `‹ ›` 切换 |
| `/` 或 ⌕ | 搜索电台名称 / 城市 / 国家，回车定位并播放 |
| `Esc` | 停止播放 / 关闭搜索 |
| 底部控制条 | 播放暂停、上一台/下一台、音量、停止、搜索 |

底部状态条会在无播放时显示电台总数或悬停电台名；`aria-live` 向读屏软件播报状态。系统开启「减少动态效果」时不自动旋转。

## 两侧面板与分级页面

- **左栏「电台目录」**：**扁平化、少层级**。分类标签固定在面板顶部（不随列表滚动，两行铺满、11 个标签全部可见）：全部 / 中国 / 各大洲 / 热门 / 收藏 / 最近，点一下即筛选，无需多层钻取；**点击大洲标签时地球同时飞向该大洲**。标签下方是一条**统计条 + 排序切换**（电台数 / 地区数 / 中国数；排序可选 默认 → 名称 → 热度，保存在本机）。列表卡片为**双行结构**：第一行站名（13.5px/600）+ 播放中均衡器，第二行「距离 · 城市, 地区 · 分级 / 同址台数」；右侧两个**浮层图标按钮**——只定位（不播放，hover 时才展开）与收藏星标，因此不占文本宽度。点击卡片 → 地球**先旋转到该点正前方、再拉近放大**（fly-to），并自动播放。**「中国」标签**直接按 国家级 / 省级 / 市级 / 网络电台 四级在列表内平铺，分级以行内小标签（金 / 蓝 / 青 / 灰）表示，无需再下钻。空态（无收藏 / 无历史 / 无匹配）带图标、说明与两个行动按钮，而不是一行灰字。顶部搜索框实时过滤。
- **右栏「播放 · 设置」**：**正在播放 hero 卡**——状态胶囊（播放中 / 连接中 / 失败 / 已暂停 / 待机）+ 分级标签、黑胶唱片（播放时缓慢旋转，中心是台名首字母）、两行不截断的台名、地点与**流来源域名**、`同址 N 台` 徽标；操作区为一个主按钮（播放 / 暂停）+ 三个线性图标（收藏 / 定位 / 复制分享链接）；下方**同址电台列表**列出同一坐标的全部电台（编号 + 名称 + 「当前」）并一键切换（`WW_EARTH.playAlt`）。再往下是附近 8 个电台（带距离徽标，元信息只显示城市以免尾部截断）、我的收藏 / 最近播放 / 显示与画质 / 快捷键与关于。**待机态**不是空白：给随机播放、展开目录两个入口，以及「继续收听」和「热门电台」两组真实条目。设置项（画质自动/高清/省电、自动旋转、地名、绿点、音量）保存在本机。
- **布局**：宽屏默认展开两栏，窄屏（<1100px）自动收起为左右边缘标签，底部控制条宽度随面板状态自适应；`F` 键或面板右上角 `×` 一键进入/退出影院模式。
- 地球与面板通过 `ww:select` / `ww:stop` / `ww:mode` / `ww:catalog` 事件双向联动：点击绿点会更新右栏详情与历史，点击列表项会定位地球并开始播放。
- **视觉与交互**：卡片与 hero 共用一套语汇——15/17px 圆角、`1px` 内高光 + 顶部受光渐变、hover 只提亮不换色相、播放态左侧绿条 + 极淡绿底 + logo 绿环；**徽标配色以所在大洲色相为家族基准、按站名哈希做 ±15° 偏移**，同洲仍可归类但不会「一屏同色字母块」；面板改为近乎不透明的深色玻璃（`blur(22px) saturate(115%)`），避免明亮卫星地表透上来把卡片冲成灰白；分类标签 chips（选中态绿色高亮、**固定栏 + 自动换行，六大洲完整显示**）；中国电台四级以**差异化配色行内标签**区分（国家级=金 / 省级=蓝 / 市级=青 / 网络电台=灰），悬停浮层 tier 同步配色；地球绿点**悬停浮层**显示电台名片；**列表卡片悬停 / 聚焦时，地球上对应点位同步高亮（青色细提示环）**；**定位标记为一条细亮环 + 缓慢呼吸柔光**，按相机到点位的距离等比缩放，任何缩放级别屏幕尺寸基本恒定；贴近地表时**拖拽灵敏度按视距收敛**（最低约为远景的 1/3）；`↑ ↓` 键盘导航列表、播放行自动滚动定位、浮层提示（toast）；数字统一千分位格式化，城市名按规范地区名显示。

## 架构要点

- **渲染**：Three.js r164 + OrbitControls（本地 `vendor/`，无 CDN 依赖）。球面 UV 与经纬度严格互逆：`phi=(90-lat)π/180`、`theta=(lon+180)π/180`。
- **纹理**：`vendor/earth-day-8k.jpg`（8K 日面）、`earth-night-8k.jpg`（夜灯）、`earth-topology.png`（凹凸）、`clouds.png`。贴近地表时按视野中心动态取 **Esri World Imagery** Web Mercator 瓦片，拼成贴合球面的局部影像层并做四边羽化；网络不可用时静默回退 8K 底图。离线部署可用 `tools/cache-tiles.py` 预取瓦片。
- **地名**：2048×2048 文字图集 + 贴合球面的 billboard 平面。可见性由球面切平面条件 `dot(dir,camDir) > R/dist` 与地球投影圆盘裁剪共同判定，因此不会出现背面漏字或文字飘出轮廓；按相机距离分级（大洲 → 主要国家 → 其余国家），并在运行时做屏幕矩形重叠剔除，字号保持屏幕像素恒定。
- **电台点**：恒定屏幕像素的纯色草绿圆点（不发光）。拾取用屏幕空间投影 + 可见半球判定，比逐点射线检测更快也更准。
- **播放**：原生 `<audio>`；播放序号防止竞态、失败流写入 `localStorage` 下次跳过、同址多电台自动换台、错误按格式/权限/网络区分提示。
- **画质**：按设备内存/移动端分档，FPS 低于 30 自动降采样、恢复后回升；WebGL 不可用时降级为平面地图 + 可点击电台列表。

## 数据管道

```bash
python tools/fetch-stations.py --pages 24        # 重建 data/radio-stations.json
python tools/optimize-textures.py               # 可选：生成 8K 高压缩比贴图（需 Pillow）
python tools/build-single-file.py                # 重建 WORLDWAVE-3D-Earth.html
python tools/cache-tiles.py --cities 北京,伦敦 --levels 8,9   # 可选：离线瓦片
```

单文件版使用 `vendor/earth-day-8k-opt.jpg` / `earth-night-8k-opt.jpg`——分辨率仍是 8192×4096，仅提高 JPEG 压缩比，把自包含 HTML 从约 13.5 MB 降到约 7.7 MB；多文件版始终使用原始贴图。若优化版缺失，构建脚本自动回退原图。在线目录刷新放在 `requestIdleCallback`，不占用首屏关键路径（实测多文件版 `load` 从 2.8s 降到 1.0s）。

`fetch-stations.py` 从 [Radio Browser](https://docs.radio-browser.info/) 社区目录分页抓取 + 按国家补齐覆盖，只保留 **https、浏览器原生编码、非 HLS** 的流（Chromium 的 `<audio>` 无法播放 `.m3u8`，`http://` 流在 HTTPS 页面会被混合内容策略拦截），按 0.02° 网格聚合并保存同址最多 4 个备选台。输出带 `meta`（生成时间、来源、策略、点位数）。

`build-single-file.py` 会写入 `ww-build` 版本戳（UTC 时间 + 源码哈希），方便识别过期单文件。

## 已知限制

- 点位密度与地域分布取决于公开目录中「填写了经纬度」的电台：**中国电台已专项补全**——`data/china-radio.json` 从 Radio Browser 的 CN 条目抓取、按省/市真实坐标地理编码、并标注 国家级 / 省级 / 市级 / 网络电台 四级（共约 355 个，含央广/CRI 国家级、各省市台与网络电台），合并进 `data/radio-stations.json`；`fetch-stations.py` 重建时会自动重新并入该文件，覆盖可持续保留。其余地区仍取决于公开目录的坐标完备度，不会伪造坐标。
- 近景卫星影像与在线目录刷新需要外网；完全离线时仍可显示内嵌的 8K 底图与 5,000+ 个点位，并可播放内置精选电台（若其流可达）。
- 电台流由第三方提供，可能随时失效；页面会记录失败并在下次自动跳过。
- 影像版权归 Esri / Maxar / Earthstar Geographics 等所有，页面底部保留署名；电台元数据来自 Radio Browser 社区。

## 部署（Vercel 静态站）

本仓库为纯静态站点，无构建步骤、无服务端依赖：

- 入口：`index.html`
- 运行依赖：`js/`（Three.js 地球与面板）、`data/radio-stations.json`（电台快照）、`vendor/`（Three.js 与 8K 贴图）
- 第三方运行时请求：Radio Browser 在线目录、Esri World Imagery 卫星瓦片（均走 HTTPS，失败时自动回落到内置快照与 8K 底图）
- `vercel.json` 仅配置静态资源缓存头

在 Vercel 中 **Add New → Project → Import Git Repository** 选择本仓库，Framework Preset 选 `Other`，Build Command / Output Directory 留空即可自动部署。

```bash
# 命令行部署（需先 vercel login）
vercel --prod
```

本地预览：

```bash
python -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

> 说明：仓库发布的是已确认的当前版本；「两行标题 / 播放卡吸顶」等提案仍在视觉评审阶段，未包含在此次部署中。
